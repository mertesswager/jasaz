# ⚡ Jasaz Deployer | نصب‌کننده خودکار ورکر و دیتابیس کلودفلر

یک وب‌اپلیکیشن شیک و مرحله‌به‌مرحله با رابط کاربری فارسی و فونت وزیرمتن که بر روی سرویس **Cloudflare Pages** میزبانی می‌شود. این برنامه به کاربران اجازه می‌دهد بدون نیاز به کار با ترمینال یا ابزار Wrangler، هرگونه اسکریپت Worker را از طریق لینک مستقیم یا انتخاب فایل محلی به اکانت کلودفلر خود اضافه کرده و در صورت نیاز دیتابیس D1 را به صورت خودکار ساخته و با متغیر دلخواه به ورکر متصل (Bind) کنند.

پروژه اصلی: [itsyebekhe/jasaz](https://github.com/itsyebekhe/jasaz)

---

## 🚀 ویژگی‌ها

- 🎨 **طراحی مرحله‌به‌مرحله (Step-by-Step Wizard):** هدایت کاربر گام‌به‌گام از ورود کلیدها تا نصب نهایی.
- 🔗 **لینک آماده API Token:** ایجاد کلید دسترسی کلودفلر با یک کلیک با دسترسی‌های از پیش تنظیم‌شده.
- 💡 **راهنمای یافتن Account ID:** آموزش دریافت شناسه اکانت از آدرس داشبورد.
- 🗄️ **یکپارچگی با پایگاه‌داده D1:** قابلیت ساخت آنی دیتابیس D1 و اتصال (Binding) متغیر محیطی به ورکر.
- 🎲 **تولید نام تصادفی:** ایجاد اسامی مجاز برای ورکرها بدون نیاز به تایپ دستی.
- 📂 **آپلود فایل محلی:** انتخاب فایل `.js` یا `.mjs` از کامپیوتر یا موبایل، بدون نیاز به لینک Raw؛ پشتیبانی از همان تنظیمات D1، KV و مبهم‌سازی.
- 🛡️ **امنیت کامل و بدون تحریم:** استفاده از Cloudflare Pages Functions جهت دور زدن محدودیت‌های CORS بدون نگهداری کلیدهای کاربر روی سرور.

## 🛠️ راهنمای استقرار این برنامه (Setup & Deploy)

این برنامه با استفاده از **GitHub Actions** به صورت اتوماتیک بر روی Cloudflare Pages دیپلوی می‌شود.

### ۱. تنظیم سکرت‌های گیت‌هاب (GitHub Secrets)
به تنظیمات مخزن خود در گیت‌هاب بروید:
`Settings` > `Secrets and variables` > `Actions` > دکمه `New repository secret`

دو سکرت زیر را تعریف کنید:

1. **`CLOUDFLARE_ACCOUNT_ID`**: شناسه اکانت کلودفلر شما.
2. **`CLOUDFLARE_API_TOKEN`**: یک توکن کلودفلر با دسترسی `Cloudflare Pages: Edit`.

### ۲. استقرار
- با هر بار `push` به شاخه `main` یا کلیک روی دکمه **Run workflow** در تب **Actions** گیت‌هاب، پروژه به صورت خودکار بیلد و در Cloudflare Pages منتشر می‌شود.

## 📖 راهنمای کار برای کاربران نهایی

1. **یافتن Account ID:**  
   در داشبورد کلودفلر وارد بخش **Workers & Pages** شوید. از نوار آدرس مرورگر (URL)، بخش بین نشانی را کپی کنید:  
   `https://dash.cloudflare.com/[اینجا_شناسه_اکانت_شماست]/workers-and-pages`

2. **دریافت API Token با دسترسی‌های مورد نیاز:**  
   بر روی دکمه تعبیه‌شده در مرحله اول برنامه کلیک کنید یا از لینک مستقیم زیر استفاده نمایید (دسترسی‌های Worker، D1 و Account پیش‌فرض تیک خورده‌اند):  
   [ساخت API Token پیش‌تنظیم شده کلودفلر](https://dash.cloudflare.com/profile/api-tokens?permissionGroupKeys=%5B%7B%22key%22%3A%22workers_scripts%22%2C%22type%22%3A%22edit%22%7D%2C%7B%22key%22%3A%22d1%22%2C%22type%22%3A%22edit%22%7D%2C%7B%22key%22%3A%22account_settings%22%2C%22type%22%3A%22read%22%7D%2C%7B%22key%22%3A%22account_analytics%22%2C%22type%22%3A%22read%22%7D%5D&accountId=*&zoneId=all&name=Nahan%20Installer)

3. **انتخاب سورس اسکریپت ورکر:**
   در گام دوم، گزینه «آدرس مستقیم (URL)» را برای وارد کردن لینک Raw انتخاب کنید، یا گزینه «آپلود فایل از دستگاه» را بزنید و فایل `worker.js` (یا هر فایل `.js` / `.mjs`) را انتخاب کنید. در حالت فایل، وارد کردن آدرس لازم نیست. فایل باید حاوی کد جاوااسکریپت و غیرخالی باشد. نام فایل انتخاب‌شده در گام تأیید نمایش داده می‌شود.

4. **اتصال D1 (اختیاری):**  
   نام دیتابیس دلخواه و نام متغیر (مثلاً `DB`) را مشخص کنید تا دیتابیس ساخته و به ورکر متصل شود.

## آزمایش تغییرات

با Node.js نسخه ۲۰ یا جدیدتر، دستور `npm test` را اجرا کنید. تست‌ها مسیر فایل محلی و لینک، اعتبارسنجی، ارسال فرم و تنظیمات D1 و KV را با درخواست‌های شبیه‌سازی‌شده بررسی می‌کنند و چیزی روی کلودفلر نصب نمی‌کنند.
